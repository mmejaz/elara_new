# Welcome to the User Guide

> **Audience:** everyone who uses the application · **Last updated:** 2026-08-19

This guide explains **what each part of the app does and how to use it** — in
plain language, no technical background needed. Looking for architecture, code,
or API details instead? See the **Developer Guide**.

## How this guide is organized

Pick a topic from the menu on the left. A good path if you're new:

1. **[Getting Started](getting-started.md)** — signing in and finding your way
   around the screen.
2. **[Your Profile](profile.md)** — your details, password, and what you can
   access.
3. Then the module you need — Users, Roles, Organizations, Departments, and so on.

## The same pattern everywhere

Almost every screen in the app works the same way, so once you learn one you know
them all:

- A **list** in the middle with a **search box**, sortable columns, and paging at
  the bottom.
- A button at the top-right (e.g. **"Add User"**) that opens a **side panel** (a
  "drawer") to create a new item.
- On each row, an **Edit** and a **Delete** action.

Whenever a doc says "open the create panel" or "edit the row", it means exactly
this pattern.

## A note on what you can see

You'll only be able to open the screens your account has permission for, and some
actions may be blocked with a message if your role doesn't allow them. If you
think you're missing access, ask an administrator to review your **roles** — see
[Roles & Permissions](roles-and-permissions.md).
