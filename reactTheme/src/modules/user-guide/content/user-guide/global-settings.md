# Global Settings

> **Where:** Management → Global Setting

Global Settings are configurable groups of options that control app-wide
behavior. Each setting defines a set of **fields**, and holds the **values**
(records) entered against those fields.

## What you can do

- Browse the available settings.
- Open a setting to view and edit its values.
- Add, edit, or remove records within a setting.

## How to use it

1. Open **Management → Global Setting**.
2. Select a setting from the list to open it.
3. Review its **fields** and the current **values**.
4. Use **Add** to create a new record, or **Edit** on a row to change one, then
   **Save**.

## Tips

- Changes here can affect the whole application, so review before saving.
- If you're unsure what a setting controls, check with an administrator — some
  settings are technical.
