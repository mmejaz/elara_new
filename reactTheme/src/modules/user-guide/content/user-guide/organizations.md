# Organizations

> **Where:** Lookups → All Lookups → Organization
> **Switcher:** the organization selector in the header

Organizations represent the companies, branches, or units you work with. They can
be arranged in a **hierarchy** (a parent organization with children under it).

## What you can do

- See all organizations in a list.
- Add an organization, optionally under a **parent**.
- Edit or delete an organization.
- **Switch** the organization you're currently working in, using the header
  selector.

## Add an organization

1. Select **Add Organization**.
2. Enter a **name**.
3. Optionally choose a **parent organization** to nest it under one you already
   have. Leave this empty for a top-level organization.
4. Select **Save**.

## The organization switcher

The selector in the header sets your **active organization**. This matters
because some data is scoped to it — most notably [Departments](departments.md),
whose list can change depending on the organization you've selected. Your choice
is remembered between visits.

## Edit or delete

- **Edit:** open the row, change the name or parent, and **Save**.
- **Delete:** remove an organization you no longer need. Move or remove its child
  organizations and departments first if it has any.

## Tips

- Use the hierarchy to mirror your real structure (e.g. *Head Office* → *Regional
  Office* → *Branch*).
- If a department list looks wrong, check which organization is selected in the
  header switcher first.
