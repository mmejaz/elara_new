# Managing Users

> **Where:** Management → Users

Create and manage the people who can sign in to the app, and control what they
can do by assigning roles.

## What you can do

- See all users in a searchable, sortable list.
- Add a new user.
- Edit a user's details.
- Assign one or more **roles** to a user (this is what grants access).
- Delete a user.

## Add a user

1. Select **Add User** (top-right). A side panel opens.
2. Fill in **name**, **email**, and the other details (phone, designation).
3. Set an initial **password** — it must meet the strength rules (8+ characters,
   mixed case, a number, and a symbol).
4. Choose one or more **roles** (see [Roles & Permissions](roles-and-permissions.md)).
5. Select **Save**. The new user appears in the list and can sign in immediately.

## Edit or delete

- **Edit:** select **Edit** on the user's row, change what you need, then
  **Save**. Leaving the password blank keeps the current one.
- **Delete:** select **Delete** on the row and confirm. This removes the account.

## Find a user

Use the **search box** above the list to filter by name or email, click a column
header to **sort**, and use the pager at the bottom for large lists.

## Tips

- Access comes from **roles**, not from the user record itself. To give someone
  more (or less) access, change their roles here or adjust the role in
  [Roles & Permissions](roles-and-permissions.md).
- A user with the **Super Admin** role can do everything — assign it sparingly.
