# Managed Modules

> **Where:** Management → Managed Modules

This screen lists the app's **modules** — the items that make up your sidebar
navigation — and lets you control which ones are visible.

## What you can do

- See every module and how it's organized (groups and their items).
- **Show or hide** a module in the sidebar.

## How to use it

1. Open **Management → Managed Modules**.
2. Find the module you want to change.
3. Toggle its **visibility** on or off. Hidden modules disappear from the sidebar
   for everyone; showing them again brings them back.

## Tips

- Hiding a module only removes it from the menu — it doesn't delete any data.
- To **create** a brand-new module (a new screen with its own list and form), use
  the [Module Builder](module-builder.md) instead.
