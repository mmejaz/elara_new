# Lookups (Reference Lists)

> **Where:** Lookups → All Lookups

"Lookups" are the simple reference lists the rest of the app draws from — the
options that appear in dropdowns and forms elsewhere. They all work the same way.

## The lookup lists

| Lookup | What it's for |
|---|---|
| **Application Type** | Categories of application |
| **Country** | Countries |
| **City** | Cities |
| **Gender** | Gender options |
| **Designation** | Job titles / designations |
| **Leave Type** | Types of leave (e.g. annual, sick) |
| **Document Type** | Types of document |

> [Organization](organizations.md) and [Department](departments.md) also live
> under All Lookups but have their own hierarchy features — see their own pages.

## How to use any lookup

Every lookup screen is the same:

1. Open it from **Lookups → All Lookups**.
2. **Add:** select the **Add** button, enter the **name** (and any related field,
   such as the country a city belongs to), then **Save**.
3. **Edit:** open a row, change it, **Save**.
4. **Delete:** remove a row you no longer need.
5. **Find:** use the **search box** and column sorting for long lists.

## Tips

- Keep names clear and consistent — they show up in dropdowns throughout the app.
- Before deleting a lookup value, remember that other records may already use it.
- Adding a new option here makes it immediately available wherever that lookup is
  used.
